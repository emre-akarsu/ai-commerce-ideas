# 01 - Agentic Commerce: Protocols, Payments, Infrastructure (as of 2026-10-02)

Method note: findings come from WebSearch result summaries plus a few page fetches. Several primary pages (McKinsey, Morgan Stanley) returned HTTP 503 on fetch, so their figures are taken from secondary citations and flagged. Many "explainer" sites (stellagent, eco.com, etc.) are low-authority aggregators; I prefer primary URLs where one appeared in results.

## 1. Landscape map (what each layer does, status, gaps)

### Commerce/checkout protocols

**OpenAI/Stripe Agentic Commerce Protocol (ACP)** - Open spec for agents to access merchant catalogs and checkout; co-developed by OpenAI and Stripe ([Stripe](https://stripe.com/newsroom/news/stripe-openai-instant-checkout)). The 2026-04-17 release added cart, feed, orders, authentication and MCP compatibility ([Digital Commerce 360 summary](https://www.digitalcommerce360.com/2026/02/16/openai-expands-agentic-commerce-push/); version detail from secondary source, unverified). A 4% merchant fee on Instant Checkout was reported (same source). Maturity: beta per [McFadyen](https://mcfadyen.com/articles/b2b-agentic-commerce-what-works-now). Key event: OpenAI scaled back native Instant Checkout on 2026-03-17, redirecting users to retailer apps (Instacart, Target, Expedia, Walmart app) ([Retail Gazette](https://www.retailgazette.co.uk/blog/2026/03/openai-pulls-back-from-in-chat-shopping-as-ecommerce-reality-bites/); [CNBC](https://www.cnbc.com/2026/03/20/open-ai-agentic-shopping-etsy-shopify-walmart-amazon.html)). Only ~30 Shopify merchants reportedly went live vs "over a million" promised ([Rye summary of reporting](https://rye.com/blog/openai-chatgpt-checkout-agentic-commerce) - secondary). Gap: consumer B2C, card-centric, merchant-of-record model; no B2B constructs.

**Google Universal Commerce Protocol (UCP) - exists.** Open-source, announced at NRF Jan 2026, spec version 2026-01-11; co-developed with Shopify, Etsy, Wayfair, Target, Walmart; endorsed by 20+ partners incl. Visa, Mastercard, Stripe, Adyen, Amex, PayPal ([Google Developers Blog](https://developers.googleblog.com/under-the-hood-universal-commerce-protocol-ucp/); [Google Merchant Center help](https://support.google.com/merchants/answer/16837055?hl=en)). Capabilities: checkout, product discovery, order management; extensions for discounts, fulfillment, identity linking; transports REST, A2A, MCP; payments pluggable, compatible with AP2. Powers checkout in AI Mode and Gemini. Shopify says UCP is on by default for every store as of 2026-06-17 ([Dealroom note](https://app.dealroom.co/news/note/shopify-turns-on-ucp-and-the-catalog-agentic-commerce-for-every-store), secondary; see also [Shopify engineering](https://shopify.engineering/UCP)). Gap: docs do not address B2B/wholesale/subscriptions (fetch summary of the Google blog).

**Google AP2 (Agent Payments Protocol)** - Cryptographically signed "mandates" (intent/cart) proving user authorization; v0.2 added "human not present" and cards, stablecoins, bank transfers. Donated to the FIDO Alliance 2026-04-28 ([Google blog](https://blog.google/products-and-platforms/platforms/google-pay/agent-payments-protocol-fido-alliance/); [The Paypers](https://thepaypers.com/payments/news/google-donates-agent-payments-protocol-to-fido-alliance)). FIDO formed an Agentic Authentication TWG (chairs CVS Health, Google, OpenAI) and a Payments TWG (chairs Mastercard, Visa), building on AP2 and Mastercard Verifiable Intent ([PPC Land](https://ppc.land/fido-alliance-forms-working-groups-to-lock-down-ai-agent-payments/)). Status: pre-release/standardizing. Gap: authorization evidence only; says nothing about contract terms, approvals chains, disputes outcome.

**MCP and A2A** - MCP (Anthropic, Nov 2024) donated to Linux Foundation's Agentic AI Foundation (AAIF) 2025-12-09; A2A moved into AAIF 2026-08-17; AAIF reportedly 250+ members, 10,000+ public MCP servers, 150+ orgs backing A2A in production ([Forbes](https://www.forbes.com/sites/janakirammsv/2026/08/19/agent2agent-joins-the-agentic-ai-foundation-alongside-mcp/); [Pebblous summary](https://blog.pebblous.ai/blog/a2a-mcp-agentic-ai-foundation-authorization/en/)). These are transport/tool layers, not commerce semantics. Gap: McFadyen notes no production mechanism for tracing authorization across agent hops or narrowing permissions between organizations ([source](https://mcfadyen.com/articles/b2b-agentic-commerce-what-works-now)).

### Card-network and wallet layers

**Visa Intelligent Commerce (VIC) + Trusted Agent Protocol (TAP)** - Tokenized credentials for agents plus an open framework using agent-specific signatures (HTTP Message Signatures, RFC 9421) so merchants distinguish legitimate agents from bots ([Visa press release](https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.21961.html)). Visa cited 100+ partners, 30+ building in sandbox, 20+ agents/enablers integrating; "hundreds" of live transactions. Live with 30 European issuers ([The Industry Spread](https://theindustryspread.com/visa-agentic-payments-live-30-european-issuers/)). Adopters: Akamai, Nuvei, Ramp (Agent Cards), InFlow ([Forbes](https://www.forbes.com/sites/johnkoetsier/2026/05/08/visa-cards-for-ai-agents-visa-and-inflow-enable-agentic-payments/)). Gap: consumer-first; B2B only indirectly via commercial cards.

**Mastercard Agent Pay** - Agentic Tokens (extension of MDES) bound to an agent, merchant scope and consent policy. Announced 2025-04-29; first live transactions in APAC, Europe (Santander, 2026-03-02), Hong Kong; LAC issuers enabled by early 2027; "Agent Pay for Machines" with 30+ partners (cards, stablecoins) June 2026 ([Mastercard LAC](https://www.mastercard.com/news/latin-america/en/newsroom/press-releases/pr-en/2025/december/mastercard-unveils-agent-pay-in-latin-america-and-the-caribbean/); [Mastercard HK](https://www.mastercard.com/news/ap/en-hk/newsroom/press-releases/en-hk/2026/mastercard-completes-its-first-live-agentic-transaction-in-hong-kong/); [Genfinity](https://genfinity.io/2026/06/10/mastercard-agent-pay-for-machines-launch/)). Verifiable Intent framework contributed to FIDO ([PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/google-and-mastercard-contribute-agentic-commerce-standards-to-fido-alliance/)). Alchemy AgentCard now supports Mastercard credentials (2026-09-17, per [fintechspecs](https://fintechspecs.com/blog/mastercard-alchemy-agentcard-agent-pay-verifiable-intent/)). Gap: dispute rules for agent error not published in results.

**American Express ACE Developer Kit + Agent Purchase Protection** (2026-04-14): five services (agent registration, account enablement, intent intelligence, payment credentials, cart context) and the only network commitment found to cover purchases resulting from agent error, for registered agents with eligibility conditions ([Amex newsroom](https://www.americanexpress.com/en-us/newsroom/articles/innovation/american-express-debuts-agentic-commerce-experiences--ace--devel.html); [DC360](https://www.digitalcommerce360.com/2026/04/14/american-express-agentic-commerce-developer-kit-purchase-protection/)). US cardholders only; consumer-oriented.

**PayPal** - Agent Ready (existing PayPal merchants become agent-payable) and Store Sync (catalog syndication; merchant stays merchant of record), announced 2025-10-28, Perplexity discoverability, OpenAI partnership ([PayPal newsroom](https://newsroom.paypal-corp.com/2025-10-28-PayPal-Launches-Agentic-Commerce-Services-to-Power-AI-Driven-Shopping)). Positioned as "flexibility over standards" ([Resultsense](https://www.resultsense.com/news/2025-10-29-paypal-agentic-commerce-flexibility/)).

**Adyen Agentic** (2026-06-16): "universal translator" with Agentic Feed, Agentic Cart (checkout, tax, fulfillment, order orchestration), Agentic Payments (tokenization, fraud, MoR flows); Universal Token Vault ([Adyen](https://www.adyen.com/press-and-media/adyen-agentic); [Finextra](https://www.finextra.com/blogposting/32060/deep-dive-adyens-universal-translator-for-agentic-commerce)). Note it includes tax/fulfillment orchestration, but consumer-checkout oriented.

**Stripe (beyond ACP)** - Agentic Commerce Suite; at Sessions (2026-04-29) launched Link wallet for agents, Shared Payment Tokens (scoped by amount, currency, merchant), Issuing for agents (single-use virtual cards, spend controls, real-time auth), Machine Payments Protocol (MPP, co-authored with Tempo) for micropayments/stablecoins ([Stripe Sessions 2026](https://stripe.com/blog/everything-we-announced-at-sessions-2026); [Stripe agentic commerce](https://stripe.com/use-cases/agentic-commerce); [Stripe suite launch](https://stripe.com/newsroom/news/agentic-commerce-suite)).

### Machine/crypto-native payments

**Coinbase x402 (+ x402 Foundation)** - HTTP 402-based stablecoin pay-per-request. Foundation announced 2025-09-23 with Cloudflare, formalized under Linux Foundation 2026-04-02. Volume figures conflict: Coinbase ~165M transactions, ~69,000 active agents, ~$50M cumulative by late April 2026 ([presenc tracker](https://presenc.ai/research/x402-protocol-adoption-tracker-2026)); another source says 154M transactions ([BEX](https://bex.co/blog/2026/04/01/x402-protocol-http-402-ai-agent-commerce-stablecoin-payments)); another ~$600M "annualized" ([Wavect](https://wavect.io/blog/x402-payments-comparison-2026/)). Real GMV is tiny (~$50M cumulative suggests very small average ticket). Ramp has an x402 alpha ([Bankless](https://www.bankless.com/read/news/ramp-adds-x402-payments-for-ai-agents)). Gap: micropayments for API/data, not physical goods, returns, or disputes.

**Startups**: Skyfire (KYAPay, JWT agent identity/wallet; ~$9.5M raised per [Tracxn](https://tracxn.com/d/companies/skyfire/__-gSNwLdAbLR2EH3jQO5ja24BZ2dqjmKWC_BS3-4pf1s)); Nekuda ($5M seed led by Madrona with Amex and Visa Ventures; secure agent wallet and mandates); Payman (SOC-2/PCI, Fifth Third custody); Crossmint (50+ chains plus card rails) ([Rye landscape](https://rye.com/blog/agentic-commerce-startups); [Stellagent](https://stellagent.ai/insights/agentic-commerce-infra-startups)). Basis Theory, Nekuda, Skyfire collectively ~ $50M (same, secondary). All small; mostly consumer/dev-wallet oriented.

### Agent identity

**Web Bot Auth** (Cloudflare-led, IETF working group chartered early 2026, HTTP Message Signatures + JWKS directory); implemented by AWS WAF, Vercel, Shopify, Akamai; foundation for Visa TAP and Mastercard Agent Pay ([Stellagent](https://stellagent.ai/insights/web-bot-auth-cloudflare-ietf); [Nerd Level Tech](https://nerdleveltech.com/web-bot-auth-ietf-standard-agent-verification) - aggregators, verify before relying). It answers "who is calling", not "is this agent authorized by a legal entity with a spending authority" - KYA (Skyfire), Amex registration, AP2 mandates fill parts. No cross-vendor KYA standard found.

### Retailer stances

- **Amazon**: blocks external agents (reportedly 47 bots blocked) and won a preliminary injunction vs Perplexity Comet on 2026-03-10 (CFAA; "with user permission but without Amazon's authorization") ([CNBC](https://www.cnbc.com/2026/03/10/amazon-wins-court-order-to-block-perplexitys-ai-shopping-agent.html); [GeekWire](https://www.geekwire.com/2026/judge-blocks-perplexitys-ai-bot-from-shopping-on-amazon-in-early-test-of-agentic-commerce/)). Runs own Rufus/Buy For Me ([CNBC](https://www.cnbc.com/2025/12/24/amazon-faces-a-dilemma-fight-ai-shopping-agents-or-join-them.html)). Implication: user-delegated credentialed agents are legally exposed without platform consent.
- **Shopify**: all-in (UCP default-on, Catalog, Agentic Storefronts) but D2C only; wholesale/B2B-only products excluded from AI channels ([Shopify Help](https://help.shopify.com/en/manual/online-sales-channels/agentic-storefronts/products); B2B on all plans since 2026-04-02 per secondary source [pravinkumar.co](https://www.pravinkumar.co/blog/shopify-b2b-agentic-storefronts-chatgpt-2026)).
- **Walmart**: UCP co-developer, in-ChatGPT app with account linking, own Sparky agent; reported in-chat purchases converted at one-third the rate of click-outs ([McFadyen citing Search Engine Land](https://mcfadyen.com/articles/b2b-agentic-commerce-what-works-now); [Constellation](https://www.constellationr.com/insights/news/walmarts-agentic-commerce-vision-practical-personalized-immersive-and-less-scrolling)).
- **Etsy**: UCP co-developer, ChatGPT/Google checkout partner ([PYMNTS](https://www.pymnts.com/artificial-intelligence-2/2026/google-launches-agentic-commerce-with-etsy-and-wayfair/)).

### B2B-specific

- **cXML/PunchOut/OCI/EDI**: PunchOut sessions are designed for human UI sessions; agents use APIs and structured orders ([TradeCentric](https://tradecentric.com/agentic-commerce/); [McFadyen](https://mcfadyen.com/articles/b2b-agentic-commerce-what-works-now)). cXML already encodes PO, invoice, punchout, catalog - the closest existing B2B "protocol", but with no agent identity/mandate semantics.
- **Procurement suites**: SAP Next-Gen Ariba with Joule intake agent (GA June 2026), Coupa five-year agentic deal with AWS (Apr 2026), Coupa claims 450+ customers running agents ([McFadyen](https://mcfadyen.com/articles/b2b-agentic-commerce-what-works-now); [Savic Tech](https://www.savictech.com/insights/next-gen-sap-ariba-btp-intake-agent-autonomous-procurement-2026/) - secondary). Amazon Business integrates with SAP/Coupa for guided buying ([Procurement Mag](https://procurementmag.com/news/how-amazon-business-sap-and-coupa-ensure-spend-visibility)).
- **Spend platforms**: Ramp Agent Cards (early access, Visa Intelligent Commerce tokens, scoped per agent/transaction), x402 alpha, MCP/CLI ([Ramp](https://ramp.com/blog/virtual-cards-for-ai-agents); [Bankless](https://www.bankless.com/read/news/ramp-adds-x402-payments-for-ai-agents)). Brex and Airbase agent features: not found in detail. Mercury launched virtual cards for agents ([Fast Company](https://www.fastcompany.com/91574324/mercury-launches-virtual-credit-cards-ai-agents)).
- **Network B2B**: Mastercard Commercial Direct Payments / B2B AP automation ([Mastercard](https://www.mastercard.com/us/en/news-and-trends/press/2025/july/mastercard-accelerates-b2b-payment-automation-globally-with-acce.html)); Visa Supplier Matching Service ([Visa](https://developer.visa.com/solutions/accounts_payable)). ## GAPS & OPPORTUNITIES I SEE (ranked)

1. **B2B agent-to-agent RFQ/quote/PO layer with contract pricing and approval chains (highest).** Every major protocol (ACP, UCP, AP2, TAP, Agent Pay) is built on public price, individual buyer, card settlement; Shopify excludes B2B pricing from agent channels; McFadyen calls cross-company autonomous transactions "not yet supported" by any major protocol. Demand signal: Forrester (20% of sellers facing agent quotes in 2026) and Gartner ($15T, though inflated). Incumbents (SAP Ariba, Coupa) are closed suites; a neutral "agentic cXML" adapter (MCP/UCP extension mapping to PunchOut, EDI, OCI) is whitespace. Risk: Coupa/SAP/Amazon Business build it first; slow enterprise sales.
2. **Delegated authority and mandate management for organizations** (who may spend what, approvals, cross-hop permission narrowing). AP2/Verifiable Intent/Amex registration cover consumer consent; Ramp Agent Cards cover card limits only. An org-level policy + approval + audit layer that emits AP2/TAP-compatible proofs and maps to ERP approval matrices is unbuilt. Risk: Ramp/Brex extend into it; FIDO standards may subsume parts.
3. **Specification matching, substitution and delivery-SLA contracts as machine-readable objects.** UCP offers consumer fulfillment options only. Industrial/MRO/food-service procurement turns on specs, equivalents and lead times; no standard found. Risk: needs deep vertical data (catalog normalization); startups like Mirakl-adjacent players may own it.
4. **Dispute, liability and evidence layer for agent transactions.** Merchants are MoR and bear chargebacks; agent traffic lacks device evidence; only Amex offers cover. A product that captures signed intent/cart mandates and produces representment-grade evidence (and insurance/warranty for agent error) is concrete. Risk: card networks will bake it into rules (FIDO Payments TWG chaired by Visa/Mastercard).
5. **Supplier-side readiness: KYB/onboarding, agent-accessible pricing APIs, tax-exemption handling.** Forrester warns suppliers without real-time pricing APIs lose; Deloitte stat: 87% of suppliers upgrading ERPs (via McFadyen, unverified). Conexiom-style document-to-API adapters exist; the gap is "agent-readiness" for long-tail distributors. Risk: services-heavy.
6. **Returns/RMA and credit-memo automation for agent purchases.** No protocol coverage found; lower urgency, likely a feature of #1/#4.
7. **Cross-vendor agent identity/KYA reputation for businesses.** Web Bot Auth proves "who", not "authorized by whom" or "trustworthy"; Skyfire is tiny. Possible, but standards bodies (IETF, FIDO) are moving; weaker standalone business.

## CONFIDENCE / WHAT I COULD NOT VERIFY

- High confidence: existence and basic design of UCP, AP2-to-FIDO, ACP, TAP, Agent Pay, Amex ACE, Stripe suite, A2A to AAIF, Amazon v. Perplexity injunction (multiple mainstream outlets).
- Medium: OpenAI scaling back Instant Checkout (reported by The Information, Retail Gazette, CNBC; the "~30 merchants" figure is secondhand); x402 volume (sources conflict: 154M vs 165M tx, $50M cumulative vs $600M annualized).
- Could not fetch: McKinsey and Morgan Stanley primary pages (503); Bain, Gartner, Forrester primary figures were confirmed only via secondary quoting. Forrester's "20% of sellers" and "one-third of payments" were not seen on Forrester's own page.
- Not found: BCG and Juniper forecasts; Brex agent features; Airbase agent features; Mastercard/Visa B2B-specific agent products (only consumer agent programs and generic virtual card AP tools); Etsy's detailed stance; any B2B dispute or tax standard for agents; Coupa "450+ customers" primary source.
- Many cited explainers (stellagent.ai, eco.com, metarouter, paz.ai, etc.) are SEO/aggregator sites; their dates and claims may include errors. Some results contain future-dated arXiv IDs and promotional framing; treat as unverified.
- "Agentic" definitions differ (influenced vs autonomous), so forecast comparisons are not like-for-like.
