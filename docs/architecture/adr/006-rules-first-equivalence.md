# ADR-006: Rules-first equivalence with sources; tiers A–D
**Status:** accepted. **Context:** ChatGPT-class models can cross-reference standard parts, so differentiation requires measured safety (red team V6); liability requires "matches per [source, date]" wording (S-L1). **Decision:** per-family required-attribute tables (deterministic); tiers A (same part), B (documented equivalent with named source+date), C (rule-matched candidate, hidden until unlocked), D (needs engineering review). LLM extracts and explains only; `model_inference` can never satisfy a critical attribute. Every source has a recorded licence status; unlicensed data is excluded from production. **Consequences:** each family needs a table, sources and an eval set before launch.
