# ADR-010: Adopt the AI Employees platform stack; list deltas
**Status:** proposed (2026-10-02). **Context:** the founder's platform stack (Supabase + Render; Python FastAPI + LangGraph + Procrastinate; Next.js + CopilotKit; packs configured by `employee.yaml`; 15 shared components) is the intended base for all use cases. **Decision:** build the purchasing pack and its new components on that stack. **Supersedes:** ADR-001 for the UI (Next.js + CopilotKit replaces HTMX; Python/FastAPI unchanged). **Adjusts:** ADR-002 (our hash-chained events remain the system of record; LangGraph's checkpointer holds agent state only), ADR-003 (send-service remains the only mail-credential holder; chat/decorator approvals alone are insufficient), ADR-004 (quarantined extractor runs outside the LangGraph tool graph), ADR-007 (Supabase RLS plus a tenant-context rule for workers with no user JWT), ADR-008 (inbound provider must support alias parsing). **Open items:** parsing sandbox on Render, Langfuse data handling, inbound email provider. See `ai-employees-stack-map.md` §4.
