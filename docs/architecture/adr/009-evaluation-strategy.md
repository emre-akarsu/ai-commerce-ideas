# ADR-009: Dev/sealed evaluation sets with statistical gates
**Status:** accepted. **Decision:** per family a dev set (tuned against) and a sealed test set (capped runs, logged); two blind labellers with κ ≥ 0.8; release gate is the **upper 95% Wilson bound of the critical-mismatch rate ≤ 2%** with ≥189 Tier A/B items per family (the smallest sample whose zero-error Wilson bound is ≤ 2%; amended 2026-10-03 from ≥150, which could never pass); any false Tier A blocks release; paired McNemar tests for model/prompt changes; extraction reported field- and document-level. Golden v0 (≥100) is a smoke test only. R0 ships a *synthetic* dev set to exercise the harness; it proves the pipeline, not the product's accuracy.
