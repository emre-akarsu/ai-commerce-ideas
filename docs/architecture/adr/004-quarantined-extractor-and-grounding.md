# ADR-004: Quarantined extractor with schema-only output and verbatim grounding
**Status:** accepted. **Context:** vendor replies/attachments are untrusted and can carry indirect prompt injection (red team S-Sec1). **Decision:** vendor content is processed by an `Extractor` that has no tools and returns only a fixed schema (`ExtractedQuote`). A separate deterministic **grounding check** requires every extracted value to appear verbatim (after whitespace/number normalisation) in the source text; ungrounded fields are blanked and flagged. Extracted text is rendered inertly. Extractor output cannot change recipients, amounts-caps, rules, or state transitions. **Consequences:** some valid quotes need human confirmation (low-confidence blanks); injection fixtures are part of CI.
